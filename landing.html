🔬 Architecture

How it's built

Built around one principle: the LLM narrates, it never decides. Every risk flag and every filter is computed deterministically in Python first.

1
LangGraph Per Feature
Each tool is its own LangGraph — fetch nodes run in parallel via ThreadPoolExecutor, then one LLM node writes the plain-English summary.
2
Deterministic Risk Flags
Portfolio concentration and correlation thresholds are fixed in Python. The LLM only narrates flags already computed — it never invents one.
3
Shared Data Layer
One yfinance wrapper and one SQLite TTL cache serve every tool — fetch once, reuse everywhere.
4
Long-Term Memory
Analysis sessions persist across restarts, powering factual "what changed" comparisons — never a judgment call.
5
Multi-Format Parsing
CSV, screenshot (vision LLM), and PDF all converge into the same structured holdings table before analysis runs.
Design Principles
What this tool deliberately does and doesn't do.
✅
Research, not prediction
No directional forecasts, no buy/sell signals — just structural facts and risk flags.
✅
Deterministic flags
Concentration and correlation thresholds are fixed Python logic, not LLM judgment calls.
✅
Always reviewable
Every uploaded holdings extraction lands in an editable table before analysis — nothing is trusted blindly.
✅
Adversarially tested
Chatbot guardrails were stress-tested against borderline advice-seeking questions, not just assumed to hold.
