🔬 Architecture

How it's built

Built around one principle: the LLM narrates, it never decides. Every risk flag and every filter is computed deterministically in Python first.

1
LangGraph Per Feature
Each tool is its own small LangGraph — fetch nodes run in parallel via ThreadPoolExecutor, then one LLM node writes the plain-English summary.
2
Deterministic Risk Flags
Portfolio concentration and correlation thresholds are fixed in Python (e.g. >25% single-stock = red). The LLM only narrates flags already computed — it never invents one.
3
Shared Data Layer
One yfinance wrapper and one SQLite TTL cache serve all four tools — fetch once, reuse everywhere.
4
Theme Classification
All 503 companies are batch-classified by business summary into 18 fixed sector/technology themes, cached for 30 days.
5
Multi-Format Parsing
CSV, screenshot (vision LLM), and PDF (text extraction + LLM) all converge into the same structured holdings table before analysis runs.
Design Principles
What this tool deliberately does and doesn't do.
✅
Research, not prediction
No directional forecasts, no buy/sell signals — just structural facts and risk flags.
✅
Deterministic flags
Concentration and correlation thresholds are fixed Python logic, not LLM judgment calls.
✅
Always reviewable
Every uploaded holdings extraction (CSV, screenshot, PDF) lands in an editable table before analysis — nothing is trusted blindly.
✅
Cache-first
Fundamentals refresh every 24h, quotes every 15min — fast for repeat lookups, gentle on rate limits.
